# API-анализ и разработка функциональности сортировки для онлайн-кинотеатра

Добавление функциональности сортировки фильмов и сериалов по рейтингу зрителей и кинокритиков

## 📌 Что в проекте

- **Sequence Diagram** — диаграмма последовательности, отображающая взаимодействие между пользователем, Web Server API, Films/Series Server API;
- **Тикет на разработку (Ticket)** — детальное описание изменений в Films Server API, Series Server API и Web Server API с указанием новых полей и параметров.

---

## 📂 Артефакты

- [Тикет на разработку](ссылка_на_файл)

## 📊 Результат

- Пользователи получили возможность сортировать список фильмов и сериалов по рейтингу кинокритиков и зрителей;
- В тикете описаны новые поля (`criticsRating`) и query-параметры (`sortBy`, `direction`) для Films, Series и Web Server API;
- Тикет согласован с командами разработки и готов к реализации.
